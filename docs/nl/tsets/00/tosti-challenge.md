# Thinking Set 0 *Tosti Challenge*

## Waar werk je aan?

In deze Thinking Set werk je aan de volgende leerdoelen:

- Ik kan bepalen **welke stappen nodig zijn** om een taak uit te voeren.
- Ik kan een taak **opdelen in kleinere stappen**.
- Ik kan die stappen in een **uitvoerbare volgorde** zetten.

## De challenge

Jullie krijgen een eenvoudige opdracht:

**Schrijf instructies waarmee iemand een tosti kan maken.**

Werk samen en schrijf jullie instructies op het whiteboard.

Als jullie klaar zijn, krijgt een andere groep alleen jullie instructies te zien.

**Zorg dat het lukt.**

## Maak je denken zichtbaar

Werk jullie oplossing uit op het whiteboard.

Gebruik gewone taal.

Als jullie denken dat jullie instructies klaar zijn, laat je ze testen.

## Test jullie oplossing

Wissel jullie instructies uit met een andere groep.

Lees de instructies precies zoals ze er staan.

Je mag de andere groep niet om extra uitleg vragen.

Kom je op een punt waarop je niet verder kunt?

Zet daar een markering.

Geef de instructies daarna terug aan de andere groep.

Verbeter jullie eigen instructies met de feedback die je hebt gekregen.

Wissel opnieuw en test nog een keer.

**Hoe ver komen jullie?**

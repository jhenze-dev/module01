# Problem Set 0

!!! learning "Je eerste Problem Set"

    In deze eerste Problem Set ga je ontdekken hoe het is om een probleem om te zetten in iets wat een computer kan uitvoeren.

    Je hoeft nog niet te kunnen programmeren. Je begint met je eigen idee, probeert dingen uit en ontdekt onderweg wat je nodig hebt.

    Het gaat deze week niet om hoeveel je al weet, maar om **hoe je aan de slag gaat wanneer je iets nog niet weet**.


## Wat moet je doen?

1. Maak [My Morning Routine](my-morning-routine.md).

   Ontwerp een dagelijkse routine en breng deze daarna tot leven in Scratch.

   Begin met het ontwerpen van de instructies voor je routine. Daarna ga je zelf ontdekken hoe je jouw ontwerp in Scratch kunt uitvoeren.


## Aanvullende uitleg en bronnen

Voor deze opdracht gebruik je **Scratch**.

Scratch werkt direct in je browser. Je hoeft niets te installeren en je hoeft Scratch nog niet te kennen.

In de opdracht vind je een korte introductie waarmee je kunt beginnen. Probeer vooral dingen uit, kijk wat er gebeurt, verander iets en probeer opnieuw.

Loop je vast? Gebruik dan de hints in de opdracht of vraag iemand om met je mee te denken.
